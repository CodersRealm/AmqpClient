Interface IMessageCreator

Defines a contract for creating various types of messages in a messaging system. Implementations of this interface are responsible for providing methods to create different message types, such as bytes, map, object, stream, and text messages, both with and without initial content. All methods are asynchronous and return tasks that complete with the created message instances.
