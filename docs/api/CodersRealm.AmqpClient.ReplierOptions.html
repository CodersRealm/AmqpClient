Class ReplierOptions

Configuration options that control where and how a replier sends reply messages. These options allow specifying an explicit IDestination, or alternatively a destination name and type to be used when creating the reply destination.

Parameters
Type Name Description
IDestination ReplierDestination

An explicit IDestination to which reply messages will be sent. When set, this destination takes precedence over ReplierDestinationName and ReplierDestinationType.
string ReplierDestinationName

The name of the destination to use for replies when ReplierDestination is not provided. This name will be used together with ReplierDestinationType to create or resolve the destination.
ReplyDestinationType? ReplierDestinationType

The type of destination to use when creating or resolving the destination identified by ReplierDestinationName, for example Queue or Topic. This value is ignored when ReplierDestination is provided.
