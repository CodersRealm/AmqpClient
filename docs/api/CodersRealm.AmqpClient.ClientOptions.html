FailoverReconnectDelayRandomFactor

Reconnect backoff random factor. 0 means no randomisation. 0.5 would mean backoff time could be (pseudo) randomly between 0.5 and 1.5 of normal reconnect backoff time. 1 would mean backoff time could be between 0 and 2x normal reconnect backoff. 2 would mean backoff time between 0 and 3x normal backoff, and so on. Default value is 0.
